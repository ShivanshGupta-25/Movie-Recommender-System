# 🌟 Overview

MovieAI is an AI-powered movie recommendation platform that combines **Machine Learning**, **FastAPI**, **React**, and **TMDB API** to provide intelligent movie recommendations with a modern and responsive user interface.

Unlike traditional recommendation systems, MovieAI enriches recommendations with live movie metadata, posters, ratings, genres, and additional details from TMDB.

# 📊 Recommendation Algorithm

MovieAI recommends movies using **Content-Based Filtering**.

Features used include

- Genres
- Keywords
- Cast
- Director
- Tagline

The combined feature vector is transformed using **TF-IDF** and similarity is computed using **Cosine Similarity**.
